★ DROP TERSOO'S ARTWORK HERE ★
==============================

Every artwork on the site already knows its own filename —
open lib/data.js and you'll see each piece's exact path, e.g:

    img: "/art/crule-wrld.jpg"

Save the real image with that exact name into THIS folder
(public/art/) and it appears on the site instantly.
No code, no config. Until then the site paints a generative
stand-in in the piece's own colour, so nothing ever looks broken.

Use big, high-quality files (1280px+ on the long edge, JPG/PNG/WebP).
